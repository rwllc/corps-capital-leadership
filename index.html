People
Right people, right seats. The Accountability Chart defines the seats. GWC tells you if you have the right person in each one.

Accountability Chart

List every function the business must run. One name per seat. GWC: Gets it / Wants it / Capacity. Any single No = wrong seat.
Function / Seat Who’s In It Gets It Wants It Capacity Notes
GWC rule: Gets it = naturally wired for this role (not trainable). Wants it = genuinely wants it, not just willing. Capacity = bandwidth, skill, and mental fit. Any single No = wrong seat, 99% of the time.

People Analyzer
